# 问题二信息泄露审计

## 决策时点

日期 $d$ 的日前购电计划在当天实际负载、实际光伏到达前生成。当天实际值只在对应十分钟时段执行后用于储能响应和费用结算，不会回写当天预测或购电计划。

## 各步骤允许访问的数据

| 步骤 | 最晚允许数据 | 代码约束 |
| --- | --- | --- |
| 层次负载与光伏候选预测 | $d-1$ 日 | 历史索引区间右端为 `d`，Python切片不含右端 |
| 在线岭回归负载预测 | $d-1$ 日 | 训练索引 `range(start,d)`；预测特征仅含滞后1日、7日和历史均值 |
| 预测器组合权重 | $d-1$ 日 | 只在 `max(start,d-28):d` 上计算历史MAE |
| 误差安全余量 | $d-1$ 日 | 误差历史区间为 `max(1,d-7):d` |
| 每周参数选择 | 生效日前一天 | 选择在当日影子策略结算前执行，只汇总此前28日记录 |
| 实时储能执行 | 当前已到达时段 | 不访问当天后续时段实际负载或光伏 |
| 全年方案对照 | 正式运行完成后 | 仅写入报告，不反馈给任何预测或决策 |

## 参数候选集说明

周选择候选集在运行前固定为六个单调风险前沿点。分位数水平升高时同步降低缩放系数，以覆盖从理论80%分位点到更保守尾部点，同时避免大量作用近似重复的组合。某周采用哪一组参数完全由该周开始前已经结算的影子策略结果决定。
