# 问题二题面约束审计

本文件把题面条件、正式实现和程序验收一一对应。最终数值以 `outputs/validation.json` 为准；任一硬约束断言失败时，`run_problem2.py` 会停止，不能生成“通过”结论。

| 题面条件 | 正式实现 | 验收方式 |
| --- | --- | --- |
| 每日 0:00 制定当日 144 个十分钟时段的计划购电量 | 日前 LP 一次生成长度 144 的 `q`，日内执行只读取、不修改 `q` | 每日时段数断言；Excel 144 项逐项复算 |
| 预测和调参不得使用当天或未来实际数据 | 第 `d` 日预测只访问索引 `<d`；每周参数选择只评分已结束日期 | `max_source_day < d`、`latest_observation_day < effective_day` |
| 计划购电全部按计划量付费 | 正常费用始终为 `sum(p_t q_t)`，不按实际使用量冲销 | 正常费用独立复算误差 |
| 供电不足可紧急购电，单价为交易时段电价的 5 倍 | 实时缺口先在功率、SOC允许范围内放电，剩余量 `e_t=max(load-pv-q-d,0)` | 紧急缺口公式残差；五倍费用独立复算 |
| 电池容量 12000 kWh，运行范围 1200–10800 kWh | 每一步限制 SOC 上下界 | 全年 SOC 最小值和最大值断言 |
| 最大充放电功率 5000 kW | 十分钟电量上限 `5000/6=833.333333... kWh` | 全年充、放电最大值断言 |
| 充、放电效率均为 90% | `S_{t+1}=S_t+0.9c_t-d_t/0.9` | 全年状态转移最大残差 |
| 2025-01-01 0:00 初始储电量为 6000 kWh | 全年首日初值固定为 6000 | 初始 SOC 断言 |
| 电池跨时段、跨日连续 | 下一日初始 SOC 等于上一日末 SOC，不做日末复位 | 跨日连续最大残差 |
| 不向外网售电 | `q,e,c,d,w` 均非负；富余量进入电池或记为弃电 `w` | 非负性和逐时段能量平衡断言 |
| 不允许无效同时充放电 | 日前 LP 采用两阶段词典序优化；实时执行按缺口符号只充或只放 | `max(min(c_t,d_t))` 断言 |
| 紧急购电只补缺口，不用于充电 | 有缺口时仅放电/紧急购电；有富余时仅充电/弃电 | 紧急购电与充电同时发生量断言 |
| 正式结果区间为 2025-02-01 至 2025-12-31 | 1 月仅用于冷启动和状态预热；正式输出 334 天 | 起止日期和天数断言 |
| 表 2 每个四小时区间含 24 个十分钟时段 | 固定切片 `[0:24]`、…、`[120:144]` | 六段数量与全年充放电汇总复算 |
| 表 3 按连续紧急购电区间汇总 | 将相邻正紧急购电时段合并，事件量为逐段求和 | 事件总量与完整逐时段紧急量复算 |
| 官方模板结构不得改变 | 复制模板结构，保留三个工作表及原行列布局，仅写结果区 | 重新读取工作簿，检查工作表、维度、行数和数值 |

费用目标包含两部分：全天计划购电费与实际发生的五倍紧急购电费。日前阶段看不到当天实际值，因此用严格因果预测及历史误差安全余量决定 `q`；日内阶段的计划费用已经固定，只需最小化当前紧急购电费。参数选择的评分采用历史已结算日的完整总费用，包含两部分费用。

附件时间列采用“时间戳为十分钟区间终点”的物理口径，共 144 段，覆盖 00:00–24:00。官方模板标签存在一格文字差异；写入保持模板既有列顺序，不移动任何数值，映射逐列记录在 `outputs/time_mapping.csv`。
